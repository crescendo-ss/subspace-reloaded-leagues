# SSRL logo sources

The artwork the site's shipped images are made from.

- `ssrl-stacked.png`: the stacked SS/RL mark. The tab icons, `app/icon.png` and `app/apple-icon.png`, are this on a black tile, scaled up so the letters fill it.
- `ssrl-wordmark-with-ships.png`: the wordmark with its two ships. The header logo, `public/images/ssrl-letters.png`, is the letters cut from it.
